# اسم المشروع: «هل يرفع تقليل حقول نموذج التسجيل نسبة إكمال التسجيل؟»

## الوصف
موقع (أو تطبيق) يتطلب من الزائر إنشاء حساب عبر نموذج تسجيل يضم 8 حقول، ويترك بعض الزوار النموذج قبل إكماله.
تساعد التجربة على اتخاذ قرار: هل نعتمد نموذجًا مختصرًا (3 حقول) بدل الحالي، دون أن تنخفض جودة الحسابات؟

## السؤال والفرضية
- القرار: هل نعتمد نموذج تسجيل مختصرًا (3 حقول) بدل النموذج الحالي (8 حقول)؟
- الفرضية: إذا قللنا حقول نموذج التسجيل من 8 إلى 3، فسوف ترتفع نسبة إكمال التسجيل بنقطتين مئويتين على الأقل، لأن كل حقل إضافي يزيد الجهد المطلوب ويدفع بعض الزوار إلى ترك النموذج.
